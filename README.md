# 👨‍💻 Portfólio — Mateus Sena

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, habilidades técnicas, projetos e formas de contato.

Atualmente, tenho foco em **Desenvolvimento Backend** e venho direcionando meus estudos também para **Engenharia de Dados**, aprofundando conhecimentos em desenvolvimento de APIs, bancos de dados, Python e SQL.

---

## 🚀 Sobre o projeto

Este portfólio foi desenvolvido utilizando **HTML, CSS e JavaScript**, com foco em organização, responsividade e interatividade.

O projeto também utiliza **Tailwind CSS via CDN** para construção e estilização da interface.

A página apresenta informações sobre minha formação, tecnologias, projetos desenvolvidos e formas de contato.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Git
- GitHub

---

## ✨ Funcionalidades

O portfólio possui:

- Tema claro e escuro
- Menu responsivo para dispositivos móveis
- Filtro de projetos por tecnologia
- Modal com detalhes dos projetos
- Validação de formulário com JavaScript
- Botão para copiar e-mail
- Navegação entre seções
- Manipulação do DOM
- Eventos utilizando `addEventListener`
- Layout responsivo para desktop, tablet e dispositivos móveis
